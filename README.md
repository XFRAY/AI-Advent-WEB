# День 27 · Память контекста локальной LLM

Веб-чат использует локальную модель `qwen3:1.7b` через Ollama и поддерживает многоходовый диалог. При каждом запросе приложение передаёт модели историю текущей беседы, поэтому Qwen понимает уточняющие вопросы и может ссылаться на предыдущие сообщения.

История хранится только в памяти открытой вкладки. Она удаляется кнопкой «Очистить» или при перезагрузке страницы. База данных, облачные модели и API-ключи не используются.

## Как это работает

```text
React (история чата) → Express → Ollama → qwen3:1.7b
```

Клиент отправляет массив сообщений с ролями `user` и `assistant`. Backend проверяет историю и целиком передаёт её локальному Ollama API. Модель получает предыдущие реплики как контекст вместе с новым вопросом.

## Установка Ollama и модели

Установите [Ollama](https://ollama.com/download), запустите приложение или сервер и загрузите модель:

```sh
ollama serve
ollama pull qwen3:1.7b
```

Если Ollama уже работает как приложение, отдельно запускать `ollama serve` не нужно.

## Запуск

Нужен Node.js 20.19 или новее.

```sh
npm install
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:5173. Backend запускается на http://127.0.0.1:3001.

Модель можно заменить через `OLLAMA_MODEL`, а адрес Ollama — через `OLLAMA_BASE_URL`.

## API

- `GET /api/llm/status` — версия Ollama и наличие выбранной модели.
- `POST /api/llm/chat` — локальная генерация с учётом истории.
- `GET /api/health` — состояние Express backend.

Пример запроса с контекстом:

```sh
curl http://127.0.0.1:3001/api/llm/chat \
  -H 'Content-Type: application/json' \
  -d '{
    "messages": [
      {"role": "user", "content": "Меня зовут Антон."},
      {"role": "assistant", "content": "Приятно познакомиться, Антон!"},
      {"role": "user", "content": "Как меня зовут?"}
    ]
  }'
```

Допускается до 40 сообщений, до 4000 символов в каждом и до 32000 символов во всей истории. Последним должно быть сообщение пользователя.

## Проверка памяти

1. Напишите: «Меня зовут Антон, мой любимый цвет — синий».
2. После ответа спросите: «Какой мой любимый цвет?».
3. Qwen должна ответить с учётом первой реплики.
4. Нажмите «Очистить» и задайте вопрос снова — предыдущий контекст больше не будет передан модели.

## Тесты и сборка

```sh
npm test
npm run build
```

Тесты используют имитацию Ollama API и не требуют установленной модели.
