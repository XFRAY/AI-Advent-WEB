# День 24 · Цитаты, источники и анти-галлюцинации

Приложение строит grounded RAG-ответ только на основе локальной базы знаний. У каждого содержательного ответа есть проверенные источники (`source`, раздел и `chunk_id`) и дословные цитаты из найденных чанков. Если релевантность контекста ниже порога, приложение не вызывает answer-модель и просит уточнить вопрос.

## Пайплайн

```text
вопрос → query rewrite → embeddings → candidate top-K
       → similarity threshold → result top-K
       ├─ нет чанков → «Я не знаю… уточните вопрос»
       └─ есть чанки → structured LLM answer → серверная проверка
                          ├─ valid → ответ + источники + цитаты
                          └─ invalid → одна repair-попытка → fail closed
```

Модель получает контекст в изолированных блоках `<source>` и возвращает JSON по строгой схеме. Сервер независимо проверяет, что ответ содержит ссылки `[S1]`, все labels существуют, а каждая цитата буквально входит в указанный чанк. После двух невалидных результатов API возвращает контролируемую ошибку вместо неподтверждённого ответа.

## Режим «не знаю»

Если после similarity-фильтра не осталось чанков, API возвращает:

```json
{
  "answer": "Я не знаю ответа по имеющемуся контексту. Пожалуйста, уточните вопрос.",
  "contextFound": false,
  "sources": [],
  "quotes": []
}
```

Порог и размеры выборки можно менять в интерфейсе. Стартовые значения задаются в `.env`:

```env
RAG_CANDIDATE_TOP_K=8
RAG_RESULT_TOP_K=3
RAG_SIMILARITY_THRESHOLD=0.35
```

## Контрольный прогон

`corpus/evaluation.json` содержит 10 вопросов к справочнику кафе. Интерфейс автоматически отмечает наличие источников и цитат для каждого ответа. Соответствие смысла ответа цитатам подтверждается вручную отдельным чекбоксом; сверху отображаются итоги по всем трём критериям.

## Запуск

Нужен Node.js 20.19+ и OpenAI API key.

```sh
npm install
cp .env.example .env
npm run dev
```

Откройте http://localhost:5173 и сначала постройте индекс. По умолчанию используются `gpt-5.6-terra` и `text-embedding-3-small`.

## HTTP API

- `GET /api/index` — состояние корпуса, индекса и RAG defaults.
- `POST /api/index/build` — построить или перестроить индекс.
- `POST /api/answer` — получить проверенный ответ либо состояние «не знаю».
- `GET /api/evaluation/questions` — получить контрольные вопросы.
- `GET /api/documents/file?path=...` — открыть файл из корпуса.
- `GET /api/health` — состояние сервера.

Пример запроса:

```json
{
  "question": "От какой суммы доставка бесплатная?",
  "settings": {
    "candidateTopK": 8,
    "resultTopK": 3,
    "similarityThreshold": 0.35
  }
}
```

Успешный результат содержит `answer`, `sources`, `quotes`, `contextFound` и объект `retrieval` с rewritten query, статистикой фильтрации и кандидатами.
