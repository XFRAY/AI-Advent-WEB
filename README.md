# День 20 · Оркестрация MCP

Агент работает с **четырьмя отдельными MCP-серверами**, каждый в своём процессе. Модель видит инструменты
всех серверов, сама выбирает нужные и вызывает их по одному в порядке зависимостей. Backend-роутер
отправляет каждый вызов на тот сервер, который объявил инструмент. Ветка предыдущего дня — `day_19`.
В проекте оставлено только то, что нужно дню 20: вход в Altegio, четыре MCP-сервера, роутер, агент и чат.

## MCP-серверы

| Сервер | Инструменты | Данные | Переменные окружения |
|---|---|---|---|
| `altegio` | `altegio_search_services { query?, limit }` | каталог услуг и цены филиала (Altegio V2) | `ALTEGIO_PARTNER_TOKEN`, `ALTEGIO_USER_TOKEN`, `ALTEGIO_LOCATION_ID` |
| `analytics` | `analytics_price_stats { items[] }` | статистика цен по валютам, код без модели | — |
| `currency` | `currency_convert { from, to, amounts[] }` | средние курсы НБП, таблица A, кросс-курс через PLN, ключ не нужен | — |
| `files` | `files_save_report { title, markdown, name? }`, `files_list_reports {}`, `files_read_report { file }` | Markdown-отчёты в `data/reports` | `REPORTS_DIR` |

**Валюта.** API услуг Altegio не присылает валюту цены. Её знает филиал: поле `currency_short_title`
в `GET /api/v1/company/{id}`, например `zł`. Сервер `altegio` один раз за процесс запрашивает филиал,
переводит символ в ISO-код (`zł` → `PLN`, `€` → `EUR`, …) и подставляет его в услуги без собственной
валюты. Если символ неизвестен или запрос не удался, `currency` остаётся `null`, а поиск всё равно
работает.

Код серверов лежит в `server/mcp/servers/<имя>/`: `server.js` — MCP-процесс по stdio, `tools.js` — описания
и zod-схемы. Их используют и сервер, и клиент.

## Как устроена оркестрация

```
модель ──(function_call name)──▶ LlmAgent ──▶ McpRegistry.callTool(name)
                                                 │ routes: name → сервер (построено при discovery)
                        ┌───────────────┬────────┴──────┬───────────────┐
                     altegio        analytics        currency          files      ← отдельные stdio-процессы
```

- **Регистрация** (`server/mcp/registry.js`). `McpRegistry` открывает по `McpConnection`
  (`server/mcp/connection.js`) на каждый сервер. Процесс получает только свои переменные окружения:
  токены Altegio не попадают в другие серверы, ключ OpenAI — ни в один.
- **Discovery.** `listTools()` опрашивает все серверы и строит таблицу маршрутов «инструмент → сервер».
  Сервер может объявить только инструменты из своего списка. Если одно имя объявили два сервера,
  discovery останавливается с ошибкой. Если сервер упал, его инструменты пропадают из списка, а
  остальные серверы продолжают работать.
- **Выбор инструмента.** Модель получает все инструменты с пометкой `[MCP-сервер …]`, а в инструкции
  описано, за что отвечает каждый сервер. Вызовы идут по одному (`parallel_tool_calls: false`), поэтому
  порядок детерминирован: данные → статистика → валюта → сохранение → список или чтение. Цифры модель
  не считает сама, курсы не придумывает.
- **Маршрутизация.** Перед вызовом `callTool` проверяет, что инструмент известен, и валидирует
  аргументы zod-схемой владельца. Некорректный вызов не доходит до сервера, модель получает понятную
  ошибку.
- **Длинный флоу.** За один запрос допускается до 12 вызовов. После этого инструменты отключаются
  (`tool_choice: 'none'`), и модель формулирует ответ из того, что уже получено. Ошибка шага
  возвращается модели, и зависимые шаги она не вызывает.
- **Трасса.** Каждый вызов записывается как `{ step, server, name, arguments, status, result, durationMs }`
  и показывается под ответом: номер шага, сервер, инструмент, параметры и результат. Над трассой видна
  строка маршрута, например `altegio → analytics → currency → files → files`.

## Запуск

Нужен Node.js 20.19+.

```sh
npm install
cp .env.example .env # только если .env ещё нет
npm run dev
```

Frontend: http://localhost:5173. Backend: http://127.0.0.1:3001.
Собранное приложение: `npm run build`, затем `npm start`.

Настройки `.env`: `OPENAI_API_KEY`, `OPENAI_MODEL`, `ALTEGIO_PARTNER_TOKEN`, `PORT`, необязательный `REPORTS_DIR`.
Чтобы подключение восстанавливалось после перезапуска, задайте `ALTEGIO_USER_TOKEN` и `ALTEGIO_LOCATION_ID`.
Вход через форму хранится только в памяти. Пароль не сохраняется, токен не возвращается браузеру
или модели. Смена токена или филиала перезапускает только сервер `altegio`.

## Как проверить

1. Войдите в Altegio через форму слева. Под формой в панели «MCP-серверы» видны все четыре сервера
   и их инструменты.
2. Задайте составной вопрос, например:
   - «Найди стрижки, посчитай статистику цен, переведи цены в EUR, сохрани отчёт и покажи список отчётов»:
     `altegio_search_services` → `analytics_price_stats` → `currency_convert` → `files_save_report` → `files_list_reports`;
   - «Сколько стоит окрашивание в долларах?»: altegio → currency, без сохранения (файл создаётся, только если попросить);
   - «Покажи последний сохранённый отчёт»: `files_list_reports` → `files_read_report`, без Altegio.
3. Под ответом проверьте маршрут и порядок шагов, а в раскрывающихся блоках — что аргументы каждого
   шага взяты из результата предыдущего. Ссылка «Открыть отчёт …» открывает сохранённый файл.

## HTTP API

- `GET /api/mcp/servers` — серверы: состояние, ошибка и инструменты.
- `POST /api/chat` `{ message }` — ответ агента и трасса `toolCalls`.
- `GET/DELETE /api/messages` — история чата.
- `GET /api/reports/:file` — сохранённый отчёт только для чтения (имя проверяется, выйти за каталог нельзя).
- `/api/altegio/*` — вход, выход и выбор филиала. `GET /api/health`.

## Проверка

```sh
npm test
npm run build
npm run mcp:list   # ✓ altegio / analytics / currency / files, 6 инструментов
```

Тесты не требуют ключей. Серверы запускаются реальными stdio-процессами; подменяются только HTTP
Altegio и НБП, а также модель — скриптом, который видит лишь определения и результаты инструментов.
Проверяется:
- discovery четырёх серверов и маршрут каждого вызова на свой процесс;
- изоляция окружения;
- отказ при неизвестном инструменте, неверных аргументах и дублировании имён;
- продолжение работы при падении одного сервера;
- перезапуск только `altegio` при смене токена;
- лимит 12 вызовов;
- сквозной сценарий `/api/chat` из шести шагов на четырёх серверах: порядок, передача данных между
  шагами, содержимое файла и ссылка на отчёт.

Документация: [услуги Altegio V2](https://developer.alteg.io/en/b2b-v2/openapi/services/list_services),
[API курсов НБП](https://api.nbp.pl/en.html), [MCP](https://modelcontextprotocol.io).
