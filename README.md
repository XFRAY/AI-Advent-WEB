# День 26 · Локальная LLM

Локальная модель `qwen3:1.7b` работает через Ollama на вашем компьютере. Веб-интерфейс отправляет сообщения в локальный Express backend, который обращается к Ollama по `127.0.0.1:11434`. Облачные API, ключи и постоянное хранение истории не используются.

## Установка Ollama и модели на macOS

Установите [Ollama](https://ollama.com/download/mac), запустите приложение или сервер, затем загрузите модель:

```sh
ollama serve
ollama pull qwen3:1.7b
```

Если Ollama уже запущен как приложение, отдельная команда `ollama serve` не нужна.

## Проверка через CLI

```sh
ollama run qwen3:1.7b "Объясни простыми словами, почему небо кажется голубым."
```

## Проверка через HTTP API

```sh
curl http://127.0.0.1:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen3:1.7b",
    "messages": [{"role": "user", "content": "Сколько будет 17 × 24? Покажи вычисление."}],
    "stream": false,
    "think": false
  }'
```

## Запуск веб-интерфейса

Нужен Node.js 20.19 или новее.

```sh
npm install
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:5173. Backend доступен на http://127.0.0.1:3001 и предоставляет:

- `GET /api/llm/status` — состояние Ollama и наличие выбранной модели;
- `POST /api/llm/chat` с `{ "message": "..." }` — один локальный запрос к модели;
- `GET /api/health` — состояние самого backend.

Модель можно заменить через `OLLAMA_MODEL`, а адрес Ollama — через `OLLAMA_BASE_URL`.

## Три запроса разной сложности

Интерфейс содержит готовые подсказки, которые можно выбрать и отправить:

1. Простой вопрос: почему небо кажется голубым.
2. Логическая задача: определить число кур и кроликов по количеству голов и ног.
3. Генерация кода: написать и объяснить JavaScript-функцию `debounce` на основе `clearTimeout` и `setTimeout`.
