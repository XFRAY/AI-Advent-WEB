# День 28 · Локальная LLM + RAG

RAG-система полностью работает на компьютере пользователя: Ollama создаёт embeddings моделью `embeddinggemma`, Node.js локально выполняет cosine-поиск по индексу Недели 6, а `qwen3:1.7b` формирует grounded-ответ. Если настроен OpenAI API, приложение параллельно показывает ответ облачной модели на том же retrieved-контексте.

```text
вопрос → embeddinggemma → локальный JSON-индекс → top-4 чанка ┬→ qwen3:1.7b
                                                               └→ OpenAI (опционально)
```

## Подготовка

Нужны Node.js 20.19+ и [Ollama](https://ollama.com/download). Установите обе локальные модели:

```sh
ollama serve
ollama pull qwen3:1.7b
ollama pull embeddinggemma
```

Если Ollama уже запущен как приложение, отдельная команда `ollama serve` не нужна.

```sh
npm install
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:5173 и нажмите «Построить локальный индекс». Предыдущий индекс на `text-embedding-3-small` несовместим и намеренно не используется: документ и запрос должны быть закодированы одной embedding-моделью.

## Облачное сравнение

Полностью локальный режим не требует API-ключей. Для второй карточки ответа добавьте в `.env`:

```dotenv
OPENAI_API_KEY=your_key
OPENAI_MODEL=gpt-5.6-terra
```

Обе модели получают идентичные четыре чанка. Ошибка или отсутствие облачной конфигурации не мешает локальному ответу. Интерфейс показывает время retrieval и генерации, проверку grounding, использованные источники, состояние вызова и ручную оценку качества.

## API

- `GET /api/rag/status` — Ollama, модели, корпус и совместимость индекса.
- `POST /api/rag/index` — локальная пересборка `data/indexes/structured.json`.
- `POST /api/rag/compare` — `{ "question": "Где есть Wi-Fi?" }`, локальный retrieval и два результата генерации.
- `GET /api/health` — состояние backend и индексации.

Индекс также можно собрать из CLI:

```sh
npm run index
```

## Проверка

```sh
npm test
npm run build
```

Тесты используют локальные имитации провайдеров и не требуют Ollama или OpenAI. Для ручной проверки без интернета сначала загрузите модели и постройте индекс, затем отключите сеть и задайте вопрос по кафе: локальная карточка продолжит работать, а облачная корректно покажет ошибку.
