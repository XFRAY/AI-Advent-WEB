# День 7: Сохранение контекста агента

Минимальное web-приложение с отдельной сущностью агента и сохранением истории диалога. Пользователь пишет запрос в чате, frontend отправляет его на backend, backend сохраняет сообщения в SQLite, передает в `LlmAgent` всю историю диалога и новое сообщение, а агент вызывает LLM через OpenAI API.

## Запуск

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env` по примеру `.env.example` и добавьте ключ:

```bash
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-5
PORT=3001
```

3. Запустите frontend и backend:

```bash
npm run dev
```

4. Откройте локальный адрес Vite, обычно `http://localhost:5173`.

## Архитектура

- `src/` — компактный React-интерфейс чата на Material UI в M3-стиле.
- `server/index.js` — Express API endpoints `GET /api/messages` и `POST /api/chat`.
- `server/LlmAgent.js` — отдельная сущность агента, которая инкапсулирует вызов LLM.
- `server/MessageStore.js` — SQLite-хранилище сообщений.

API-ключ используется только на backend и не отправляется в браузер.

История хранится в локальном файле `server/data/messages.sqlite`. Этот файл создается автоматически при запуске backend и не коммитится в git.

После каждого ответа интерфейс показывает служебную статистику: модель, температуру, input/output/reasoning/total tokens и примерную стоимость запроса. Стоимость считается на backend по локальной таблице цен для `gpt-5`, `gpt-5-chat-latest`, `gpt-5-mini` и `gpt-5-nano`; это оценка, а не бухгалтерский чек.

## Проверка сохранения контекста

1. Запустите приложение:

```bash
npm run dev
```

2. Напишите агенту факт, например:

```text
Меня зовут Антон, мой любимый цвет зеленый.
```

3. Остановите приложение и запустите его снова:

```bash
npm run dev
```

4. Убедитесь, что прошлые сообщения снова отображаются в чате.

5. Спросите:

```text
Какой мой любимый цвет?
```

Агент должен ответить с учетом сохраненной истории.

Кнопка `Reset` в шапке чата очищает всю сохраненную историю и возвращает интерфейс к стартовому сообщению.
