# День 23 · Реранкинг и фильтрация

Приложение сравнивает два RAG-режима на одном вопросе. Raw RAG ищет по исходному вопросу и сразу передаёт `top-K` чанков модели. Improved RAG сначала переписывает вопрос в поисковый запрос, получает расширенный пул кандидатов, отсекает результаты по similarity и ограничивает итоговый контекст отдельным `top-K`.

## Два режима

```text
Raw RAG:      вопрос → embedding → cosine search → top-K → LLM
Improved RAG: вопрос → query rewrite → embedding → candidate top-K
                      → similarity threshold → result top-K → LLM
```

Переписанный запрос используется только для поиска. Модель отвечает на исходный вопрос и получает только прошедшие фильтр чанки. Если ни один кандидат не достиг порога, приложение возвращает «Релевантный контекст не найден» без лишнего вызова answer-модели.

Интерфейс показывает rewritten query, количество кандидатов до и после каждого этапа, similarity и причину исключения каждого чанка. Ошибка одного режима не скрывает успешный результат второго.

## Настройки

Параметры можно менять в интерфейсе. Их стартовые значения задаются в `.env`:

```env
RAG_CANDIDATE_TOP_K=8
RAG_RESULT_TOP_K=3
RAG_SIMILARITY_THRESHOLD=0.35
```

`candidateTopK` допускает значения `1..20`, `resultTopK` — от `1` до `candidateTopK`, а similarity threshold — от `-1` до `1`.

## База знаний и контрольный набор

Корпус состоит из одного простого справочника вымышленного кафе «Север». Его короткие разделы содержат однозначные факты об адресе, меню, доставке, бронировании и программе лояльности. Такой набор позволяет сразу понять, какой чанк должен быть найден. Structured-индекс строится атомарно и совместим с обоими режимами.

`corpus/evaluation.json` содержит 10 вопросов, ожидаемые ответы и целевые источники. Полный прогон последовательно сравнивает Raw и Improved RAG; качество обоих ответов отмечается вручную.

## Запуск

Нужен Node.js 20.19+ и OpenAI API key.

```sh
npm install
cp .env.example .env
npm run dev
```

Откройте http://localhost:5173 и сначала нажмите «Построить индекс». По умолчанию используются `gpt-5.6-terra` и `text-embedding-3-small`.

Индекс также можно построить из CLI:

```sh
npm run index
```

## HTTP API

- `GET /api/index` — состояние корпуса, индекса и серверные RAG defaults.
- `POST /api/index/build` — атомарно построить или перестроить индекс.
- `POST /api/compare` — сравнить Raw и Improved RAG.
- `GET /api/evaluation/questions` — получить контрольный набор.
- `GET /api/documents/file?path=...` — открыть файл из корпуса.
- `GET /api/health` — состояние сервера.

Пример запроса:

```json
{
  "question": "От какой суммы доставка бесплатная?",
  "settings": {
    "candidateTopK": 8,
    "resultTopK": 3,
    "similarityThreshold": 0.35
  }
}
```

## Проверка

```sh
npm test
npm run build
npm run corpus:pdf
```

Тесты не обращаются к OpenAI: детерминированные doubles проверяют rewrite, pre/post top-K, границу threshold, пустой контекст, частичный успех и HTTP API.
