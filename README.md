# День 14: Инварианты и ограничения состояния

Web-приложение хранит обязательные правила ассистента отдельно от диалога, памяти и профиля пользователя. Инварианты имеют более высокий приоритет, всегда передаются модели первым дополнительным `system`-блоком и сохраняются при очистке памяти.

Поддерживаются четыре явные группы:

- `architecture` — выбранная архитектура;
- `technicalDecisions` — принятые технические решения;
- `stackConstraints` — ограничения по стеку;
- `businessRules` — бизнес-правила.

Каждая строка поля считается отдельным активным правилом. Формулировки `Не использовать ...`, `Запрещено: ...`, `Использовать только ...` и их английские аналоги участвуют в deterministic conflict guard. Если запрос явно требует нарушить такое правило, API возвращает `409` и не вызывает модель.

При первом запуске создаётся Android-набор инвариантов: MVI без MVVM/MVP, SOLID и Clean Architecture, Kotlin, Coroutines/Flow, Jetpack Compose, JUnit 5, Mockito и Hilt. Java, RxJava, Android Views и XML layouts запрещены. Бизнес-функции покрываются unit-тестами, а критические пользовательские сценарии — UI-тестами.

## Запуск

```bash
npm install
npm run dev
```

Frontend обычно доступен на `http://localhost:5173`, backend — на `http://127.0.0.1:3001`.

Настройки окружения:

```bash
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-5.6-terra
OPENAI_TOKEN_COUNTING=estimate
PORT=3001
```

## Порядок контекста

1. Базовая system-инструкция агента.
2. Обязательные инварианты.
3. Активный профиль пользователя.
4. Long-term memory.
5. Working memory.
6. Short-term dialogue.
7. Текущий запрос.

Инварианты не извлекаются из диалога автоматически. Они редактируются только явно через UI или API.

## API

- `GET /api/invariants` — текущие инварианты и число активных правил.
- `PUT /api/invariants` — полная замена текущего набора инвариантов.
- `DELETE /api/invariants` — очистка инвариантов.
- `POST /api/chat` — проверка конфликта, сборка контекста и запрос к модели.
- `DELETE /api/memory` — очистка диалога и working/long-term memory без удаления инвариантов.

Пример конфликта:

```text
Инвариант: Не использовать Python
Запрос: Используй Python для нового сервиса
Ответ: Не могу предложить это решение, потому что оно нарушает инвариант: Не использовать Python
```
